# Anxiety Analysis Dashboard (Excel)

## Project Overview

This project explores factors associated with anxiety levels using an interactive Excel dashboard built from a dataset of 11,000 observations.

The objective was to identify relationships between anxiety levels and lifestyle, health, and demographic variables through data cleaning, feature engineering, pivot table analysis, and dashboard visualization.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Dashboard Design
* Data Cleaning

## Analysis Process

1. Cleaned and prepared the dataset.
2. Created custom categories for age, sleep duration, physical activity, heart rate, stress levels, diet quality, and therapy frequency.
3. Built Pivot Tables to explore relationships between variables.
4. Designed an interactive dashboard for data exploration.
5. Identified key factors associated with anxiety levels.

## Key Insights

* High stress levels were strongly associated with higher anxiety scores. Participants in the highest stress category reported anxiety levels more than twice as high as those in the lowest stress category.

* Sleep duration showed a significant relationship with anxiety. Individuals sleeping less than seven hours per night reported the highest anxiety levels.

* Participants with a family history of anxiety displayed higher average anxiety scores than those without a family history.

* Recent major life events were associated with increased anxiety levels.

* Anxiety levels showed minimal variation across gender groups, suggesting other factors had a stronger influence.
